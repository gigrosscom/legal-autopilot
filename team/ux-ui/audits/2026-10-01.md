# UX/UI-аудит прода konsilier.com — 01.10.2026 (первый)

**Кто:** UX/UI-дизайнер. **Версия прода:** build `1790864969364` (ветка `claude/zealous-volta-a3ipv6` @ `27b555b`, PR #139).
**Как:** Chromium (Playwright) через прокси среды, доверие только CA прокси (`--ignore-certificate-errors-spki-list`,
решение владельца 01.10). Профили: **390** — iPhone + Chrome iOS (CriOS UA, dpr 2), **360** — Android Chrome (dpr 2),
**1440** — Mac Chrome. Языки **ru** и **kk**. Экраны: главная, меню, чат (пустой, ожидание, с ответом), /app,
/ops (вход), /for-lawyers, /terms. Тестовый вход — `?src=team-test`, без входа в аккаунт.
Кроме глаз — автопроверки на каждом экране: горизонтальная прокрутка, касания < 44 px, контраст WCAG (4.5:1 / 3:1),
«висящее» последнее слово, перекрытие кнопок, обрезанный текст. Безопасные зоны iPhone — через CDP
`Emulation.setSafeAreaInsetsOverride` (сверху 47, снизу 34 px, как у iPhone с полоской «Домой»).

Горизонтальной прокрутки нет ни на одном экране и ширине. Клавиатура в эмуляции не проверяется (нужно устройство).

Скриншоты — в [2026-10-01/](2026-10-01/): `before-*.png` — прод до правок, `after-*.png` — локальная сборка ветки
`claude/team-ux-2026-10-01`.

## Что хорошо

- Нет горизонтальной прокрутки, нет перекрытий кнопок на всех 3 ширинах и 2 языках.
- Шапки учитывают верхнюю безопасную зону (`pt-[env(safe-area-inset-top)]`), `viewport-fit=cover` включён.
- Подпись «Отправляя сообщение…» уже ровная (правило 1, PR #138) и пропадает после первого сообщения.
- Заголовок главной в kk на 360 переносится ровно (3 строки), дефис «ЖИ‑көмекші» неразрывный.
- Пункты меню и вкладки — ≥ 44 px; поле ввода чата 44 px.
