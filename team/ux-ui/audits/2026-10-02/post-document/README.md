# Экран дела после создания документа — упрощение (iPhone)

Владелец: экран перегружен, клиент не понимает, что делать. Переделали по спецификации владельца.

## Что было (ДО)
На одном экране разом: плашка «Важно», документ, большой блок «Как подать», ряд из 5 кнопок,
«Куда отправим», пошаговая инструкция и реферал. Приходилось долго скроллить, главное действие терялось.

- `before/main-390-ru.png` — верх экрана (iPhone, 390px, ru)
- `before/main-full-ru.png` — весь экран целиком (видно перегруз)
- `before/main-390-kk.png` — то же на казахском

## Что стало (ПОСЛЕ)
1. **Шапка** — название документа + статус («Оплачено»).
2. **Одна карточка документа** — название, статус-бейджи («Оплачено», «Подписан ЭЦП», «Ждём ответ до …»)
   и две второстепенные кнопки: «Скачать», «Распечатать».
3. **«Этапы дела»** — компактная вертикальная лента из маршрута дела (роадмап): Документ составлен ✓ →
   Подписать (Сейчас) → Отправить → Ждём ответ (до даты) → Если откажут/молчат — иск в суд.
4. **Один главный шаг** в нижней кнопке: не подписан → «Подписать»; после → «Отправить»; после отправки →
   «Отметить: ответ получен / не пришёл» (как было).
5. Реферал «Отправьте другу» — в самом низу.

Каждое действие открывает свой bottom sheet (доступный: фокус, Esc, затемнение, не перекрывается
клавиатурой, безопасные зоны iPhone):
- `after/sheet-sign-ru.png` — «Подписать»: ЭЦП (eGov / NCALayer) или распечатать и подписать от руки.
- `after/sheet-send-ru.png` — «Отправить»: «Как подать» (куда, срок, способы), «Куда отправим» с
  «Подписать и отправить», «Я подал документ сам».
- `after/sheet-download-ru.png` — «Скачать»: PDF или Word.

- `after/main-390-ru.png` — главный экран (iPhone 390px, ru)
- `after/main-full-ru.png` — весь экран целиком (простой: шаг + вехи + 2 кнопки + реферал)
- `after/main-390-kk.png`, `after/main-360-kk.png` — казахский (390 и 360px, без переполнения)
- `after/main-390-dark.png` — тёмная тема

Скриншоты сняты Playwright (Chromium, UA Chrome iOS) с заглушкой API на действующем коде ветки.
