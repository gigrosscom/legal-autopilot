# Дизайн-система Konsilier — шпаргалка для разработки

Полная версия — брендбук 1.1: `team/brand/Konsilier_Brandbook_1.1_RU.pdf` (и `konsilier-brandbook.html`).
Значения задаёт код: `apps/web/app/globals.css`. При расхождении правим код и брендбук вместе.

| Что | Правило |
|---|---|
| Название | Konsilier / Консильер (продукт), Конси (помощник), Konsilier AI (компания). Без «é». |
| Синий действия | `--color-action` #0866ff — кнопки, пузырь клиента, фокус. Один главный синий на экран. |
| Синий текста | `--color-brand` #0064e0 (тёмная — #5aa9ff) — ссылки. |
| Текст | #0d0d0d / вторичный #4f4f55 / третичный #6e6e73. Контраст ≥ 4.5:1. |
| Поверхности | фон #fff, карточки #f0f0f0 без рамки и тени, нажатое #e4e6eb. Тёмная: #141416 / #232326 / #2e2e32. |
| Шрифт | SF Pro → Inter; 400 и 600. Тело 17/1.47, чат 18/1.45, поле ввода 20 (≥ 19), подписи 12–14. |
| Кнопки | таблетка, min-h 44 (крупная 48), 15/17 px; primary / ghost / danger; кнопки одного блока одинаковые. |
| Радиусы | 8 / 12 (поля) / 18 (карточки) / 24 (ввод) / 980 (кнопки). |
| Отступы | шаг 4/8; разделы 56 (телефон) / 96 (компьютер); ширины 360/390/768/1440 без горизонтальной прокрутки. |
| Касание | ≥ 44 × 44 px. Безопасные зоны iPhone у шапки и поля ввода. |
| Иконки | линия 1.75, скруглённые концы, 20–24 px. Эмодзи в интерфейсе нет. |
| Типографика | `text-wrap: balance` у коротких абзацев; имена, цены, даты — nowrap; kk составные слова — неразрывный дефис; без U+0301. |
| Документы клиента | Times New Roman 14, A4, поля 25/15/20/20, чёрный, без бренда (docstyle.py). |
| Движение | 0,35 с, только opacity/transform; prefers-reduced-motion — без анимации. |
