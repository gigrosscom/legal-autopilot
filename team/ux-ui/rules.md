# Правила UX/UI (из замечаний владельца)

1. **01.10 — подписи под полем ввода.** «Отправляя сообщение, вы принимаете Пользовательское соглашение» на iPhone
   переносилось неровно (одно слово на второй строке). Правило: короткие подписи — по центру, `text-wrap: balance`,
   ссылки и устойчивые словосочетания — `whitespace-nowrap`, одинаковые боковые отступы. Исправлено PR #138.
2. **01.10 — проверять на устройстве владельца.** iPhone + Chrome (CriOS) — основной сценарий владельца; каждый
   аудит включает ширину 390 и UA Chrome iOS.
3. **01.10 — кнопки одного блока одинаковые.** «Что это за бардак — разные шрифты и формы» (окно «Войти или
   зарегистрироваться»). Правило: все кнопки одного блока — один шрифт, высота, ширина, радиус и стиль иконок;
   сторонние кнопки (Google/Apple) оборачиваем в наш стиль.
   - Было: Google — своя кнопка GSI (шрифт Google, 40 px, уже колонки, другой радиус), Apple — чёрная заливка и
     иконка-человечек в заглушке, e-mail/ЭЦП/eGov — наши контурные 48 px.
   - Стало: 5 кнопок `SIGNIN_BTN` (w-full в колонке max-w 400 px, min-h-12, rounded-full, border-line, 17 px
     semibold, иконка 20 px слева, space-y-3); у Google наша кнопка, а настоящая GSI лежит сверху прозрачной;
     у Apple — логотип Apple. Заглушка «скоро» — тот же стиль, text-muted. PR #152.
4. **01.10 — ударение в бренде только одним символом.** «Консилье́р» с отдельным знаком ударения (е + U+0301) в
   Inter рисуется над «р». Правило: бренд пишем «Консильéр» с é (U+00E9), комбинируемые знаки в текстах интерфейса не
   используем. Проверка — поиск U+0301 в `lib/dict`. PR #155.
5. **03.10 — синий только с контрастом AA.** Владелец утвердил #0866ff вместо #0084ff. Правило: белый текст на
   синем — не меньше 4.5:1 (#0866ff = 4.82). Синий текст на белом и на сером #f0f0f0 — #0064e0 (5.39 / 4.73). Новые
   оттенки синего добавляются только токенами в `globals.css` с цифрой контраста в комментарии. PR #243.
6. **03.10 — отчёты только ПМу, не владельцу.** Пишу в `team/reports/ux-ui-ДАТА.md`, новый отчёт сверху. Первая строка — время отправки (Алматы, ДД.ММ ЧЧ:ММ). Затем только три блока: «Сделано», «Блокеры», «Буду делать», по пунктам 1–3.
   Подробности — только по вопросу владельца.
