# Подача в госорганы и суды прямо с Konsiliér AI

Задача владельца от 29.09.2026: человек входит на нашем сайте, а мы на бэкенде подаём его обращение, жалобу или иск
в eOtinish и Судебный кабинет — «в три клика, не отходя от кассы».

## Этап 1 — сделано 29.09 (PR #43, в проде)
Блок «Подать онлайн» на каждом готовом документе, который подаётся онлайн:
1. Скачать документ и скопировать текст обращения (получатель уже вписан).
2. «Открыть eOtinish» (госорганы) или «Открыть Судебный кабинет» (суды) и короткая инструкция по отправке.
3. Нажать «Документ подан» — запускаются срок ответа и напоминания.

Вход и подпись на портале — ЭЦП или eGov Mobile пользователя. Подаёт сам человек, от своего имени.

## Почему нельзя сразу «подать с нашего бэкенда»
- eOtinish и Судебный кабинет авторизуют человека через eGov IDP / ЭЦП. Войти за человека «через наш сайт» нельзя:
  это чужая авторизация, и так делать запрещено.
- Открытого API для подачи обращений или исков сторонними сервисами у них не нашли (проверить у операторов).
- Автоматизация браузером от имени человека (скрейпинг форм) — риск для ЭЦП человека и нарушение правил порталов.

## Этап 2 — официальная интеграция (нужен ТОО и договорённости)
| Шаг | Кто | Что нужно |
|---|---|---|
| 1 | Владелец | ТОО с БИН (в процессе) |
| 2 | Разработка + финансист | Заявка на подключение к Smart Bridge (sb.egov.kz). По открытым источникам подключение для ТОО бесплатное, 5–15 рабочих дней до тестовых ключей (оценка, проверить на sb.egov.kz). Найти в каталоге сервисы eOtinish (подача обращения, статус) и условия доступа для частных ИС. |
| 3 | Разработка | Требования ИБ к информационной системе (аттестация, размещение данных в РК — серверы уже в kz1), соглашение с оператором «Зерде» / НИТ |
| 4 | Владелец + юрист | Судебный кабинет: запрос в Верховный Суд / ДОСАС на интеграцию. Пример — debex.kz подаёт заявления о выдаче судебного приказа в 700+ судов через API (основание — уточнить) |
| 5 | Разработка | После доступа: кнопка «Подать» — подпись ЭЦП/eGov Mobile на нашем сайте (уже есть) → отправка через шлюз → номер обращения и статус в деле автоматически |

## Что есть в каталоге Smart Bridge (проверено 29.09.2026 по публичному API каталога sb.egov.kz)
Всего в каталоге сотни сервисов госорганов; «ALL» — сервис виден всем и доступен по заявке (владелец сервиса одобряет).

| Для чего нам | Сервис | Кто владелец (ИС) | Что делает |
|---|---|---|---|
| Вход через eGov на нашем сайте | MIND-S-0415 | Портал «электронного правительства» | IDP/SSO: авторизация клиентов через idp.egov.kz по OAuth 2.0 для внешних систем |
| Вход по номеру телефона | ORGFG-A-4220, CMI-S-0423 | Mobile ID | Авторизация пользователя по номеру телефона (одноразовый код) |
| Заявление в полицию | MVD-S-8650 (REST), MVD-S-8826 (SOAP) | МВД, «SOS 102» | Приём текстовых заявлений граждан в полицию из мобильных приложений |
| Статус обращения eOtinish | ORGB7-S-5159 | ИС «Е-өтініштер» | Приём уведомлений об изменении статуса обращений |
| Суд (административные иски по АППК) | DODSVS-S-3527, DODSVS-S-5692, DODSVS-S-7171 | «Төрелік» (суды) | Электронные иски по АППК приходят в суд **через eOtinish**; статусы — обратно |
| Долги по исполнительному производству, алименты | MINJ-S-0239 и др. | АИС исполнительного производства | Сведения о задолженностях (сейчас — для госорганов соцпомощи) |

**Чего в каталоге нет:** публичного сервиса «подать обращение в eOtinish из частной системы». Связи eOtinish в каталоге —
межведомственные (eOtinish ↔ суды, прокуратура). Значит, для прямой подачи нужна отдельная заявка владельцу eOtinish
(запрос нового сервиса или подключения). Вероятность и сроки — неизвестны, выясняем.

**Порядок:**
1. Сразу после ЭЦП юрлица: заявки на MIND-S-0415 (вход через eGov) и Mobile ID — это даёт «вход в один клик» и
   подтверждённую личность для подачи.
2. Заявка на MVD-S-8650 (заявления в полицию) — первый канал прямой подачи.
3. Запрос владельцу eOtinish на подключение подачи обращений и получение статусов; параллельно — Верховный Суд.
