# Адресата выбирает система — формат данных для экрана (ZANN → разработчик)

Решение владельца 02.10: клиент не выбирает, куда жаловаться. Данные и бэкенд — PR #184 (`claude/team-debt-forums`),
экран — ветка разработчика `claude/team-auto-recipient`.

## Что уже делает бэкенд (#184)
- `packs/kz/routes.yaml` — правило маршрута для каждого спора общего пути (17 типов) и каждого сценария со спором (29).
- Общий путь: первый шаг выбирается сам (`Coverage.first_forum`). Список «Куда обратиться» с кнопкой «Выбрать» больше
  не приходит (`coverage.options == []`), кроме случаев:
  - клиент написал, что дело уже в суде или в полиции (флаг `pending`);
  - у спора нет правила (сейчас: `family.divorce`, `family.property_division`, `family.child_residence`).
- В карточке дела новое поле `recipients` (тип `RecipientStep[]` в `apps/web/lib/api.ts`):

```json
"recipients": [
  {"step": 1, "kind": "forum", "key": "kz.counterparty.claim", "name": "Организация или человек…",
   "label": "Должник — письменное требование вернуть долг", "when": null,
   "why": "Если срок возврата не указан, должник обязан вернуть деньги в 30 дней со дня требования…",
   "norm": "ГК РК (Особенная часть), ст. 722 п. 1; ГК РК, ст. 180 п. 3"},
  {"step": 2, "kind": "forum", "key": "kz.court.district", "name": "Районный (городской) суд по подсудности",
   "label": "Районный (городской) суд по месту жительства должника — иск", "when": "если за 30 дней не вернул",
   "why": "Иск подают по месту жительства ответчика; срок исковой давности — 3 года…", "norm": "ГПК РК, ст. 29 ч. 1…"}
]
```

- `kind`: `forum` (реестр), `authority` (pack.yaml → authorities), `party` (вторая сторона; `name` — null, имя берётся
  из дела).

## Что показать на экране
- Вместо списка: «Шаг 1 — {label}» + «Почему: {why}» + мелко `{norm}`.
- Ниже: «Если не поможет: шаг 2 — {label} ({when})».
- Кнопку «Выбрать» убрать. Если `coverage.options` не пуст, это редкий случай (дело уже в суде или нет правила):
  показывать старый список.

## Что не входит
- Судебный приказ для долга по расписке: ГПК ст. 135 такого основания не содержит, только иск (проверено 02.10).
