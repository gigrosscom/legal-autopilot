# Заявка на подключение: ORGB7-S-5159 — Приём уведомлений о статусах обращений (ИС «Е-өтініштер»)

**Сервис:** ORGB7-S-5159, ИС «Е-өтініштер»: приём уведомлений об изменении статусов обращений в другой системе.

**Цель (рус):** показывать гражданину в его деле на konsilier.com статус обращения, поданного через eOtinish
(зарегистрировано, передано исполнителю, дан ответ), и вовремя напоминать о следующем шаге.

**Примечание для заявки:** если сервис предназначен только для межведомственного обмена, просим сообщить, какой
сервис позволяет частной ИС получать статусы обращений, поданных пользователем, по его согласию (связано с запросом
06).

**Данные:** номер обращения, статус, дата, орган-исполнитель. **Нагрузка:** до 2 000 уведомлений в сутки.
**Сеть:** IP 94.131.93.236.
