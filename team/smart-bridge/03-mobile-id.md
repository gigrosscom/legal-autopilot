# Заявка на подключение: ORGFG-A-4220 — Авторизация по номеру телефона (Mobile ID)

**Сервис:** ORGFG-A-4220, ИС «Mobile ID»: авторизация пользователя по номеру мобильного телефона с одноразовым кодом
(асинхронно). Альтернатива — CMI-S-0423 «Mobile ID» (строгая идентификация пользователей eGov).

**Цель (рус):** вход на konsilier.com по номеру телефона с подтверждением оператора связи; подтверждённый номер для
уведомлений о сроках ответа госоргана.

**Цель (каз):** konsilier.com сайтына байланыс операторы растаған телефон нөмірі арқылы кіру; мемлекеттік органның жауап
беру мерзімдері туралы хабарламалар үшін расталған нөмір. *(перевод ИИ, вычитать)*

**Данные:** номер телефона (MSISDN), результат подтверждения.

**Правовое основание:** как в заявке 02. **Нагрузка (оценка):** до 3 000 запросов в сутки. **Сеть:** IP 94.131.93.236.
