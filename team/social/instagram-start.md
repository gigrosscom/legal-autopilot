### 1.5 Тип аккаунта и настройки

По справке Instagram: [Set up a professional account](https://help.instagram.com/502981923235522).

1. Настройки → «Для профессионалов» → «Тип аккаунта и инструменты» → «Переключиться на профессиональный аккаунт».
2. Тип — **Бизнес** (не «Автор»): нужен для связи со Страницей Facebook и для Meta Business Suite.
3. Категория и контакты — по таблице 1.2. Сделать категорию видимой в профиле.
4. Аккаунт — публичный.
5. Связать со Страницей Facebook через Центр аккаунтов (пароль Facebook вводит владелец).
6. Не включать: продвижение постов, Meta Verified, подписки, пробные периоды.
7. Двухфакторную защиту включает владелец сам (`accounts.md`, раздел «Что расширение не делает»).

Публикация с компьютера: в instagram.com можно публиковать посты, карусели и Reels. Stories с компьютера удобнее
публиковать и планировать в Meta Business Suite (business.facebook.com → «Планировщик»), когда Instagram связан со
Страницей Facebook. Работает ли это для вашего аккаунта — проверить при первой публикации.

### 3.3 Стиль (для всех постов)

- Цвета продукта (`apps/web/app/globals.css`): белый `#ffffff` — фон; тёмно-синий `#0e2a5a` — фон обложек и
  заголовки; почти чёрный `#0b172a` — основной текст; серо-голубой `#8796b5` — акцент (полоса под заголовком, номера,
  казахская строка на тёмном фоне); `#556174` — казахская строка на белом; линии `#e2e7ee`.
- Знак K, как в логотипе: вертикальная планка и верхнее плечо тёмные, нижнее плечо серо-голубое. На тёмном фоне
  знак белый с серо-голубым нижним плечом. Знак и «Konsiliér AI» — слева вверху каждого слайда, счётчик «2/7» — справа.
- Шрифт Inter (шрифт сайта), жирный для заголовков. Русский — крупно, казахский — строкой ниже, мельче.
- Без Фемиды, весов, молотков, стоковых фото и фото людей. Только типографика, знак K и полоса-акцент в форме
  нижнего плеча K.
- Размер каруселей 1080×1440 (3:4). Instagram сохраняет исходное разрешение для ширины 1080 и соотношения от 1.91:1 до
  3:4 ([справка Instagram](https://help.instagram.com/1631821640426723/)). Reels — 1080×1920 (9:16), текст — в
  центральной зоне 3:4, чтобы обложка в сетке не обрезала его.
- Reels собраны без звука. Перед публикацией можно добавить музыку из библиотеки Instagram в приложении, это
  необязательно. Бизнес-аккаунтам доступна не вся музыка: выбирать из того, что предлагает Instagram.

### 3.4 Правила постов

- Подпись: ru, затем kk. Ссылки в подписи Instagram не кликаются, поэтому пишем «Ссылка в профиле» и адрес для
  копирования `konsilier.com/?src=instagram`.
- Хэштеги — не больше 5, в конце подписи.
- Alt-текст (Расширенные настройки → «Альтернативный текст») — вставлять для каждого слайда, если поле доступно.
- Комментарии не отключать. Отвечать от имени Konsiliér AI расширение не должно (`publish.md`, правило 4): вопросы
  выписывать в `team/clients.md` без имён.

## 5. Для расширения: порядок публикации

1. Проверить, что аккаунт Instagram Konsiliér AI открыт в браузере и что это бизнес-аккаунт. Нет входа → «не
   опубликовано: нужен вход», стоп.
2. Проверить, что файлы поста есть в репозитории (`team/social/assets/instagram/ig-NN/`). Нет файла → пропустить
   пост, отметить «не опубликовано: нет файла».
3. Карусель: «Создать» → «Публикация» → выбрать все PNG поста по порядку 01, 02, … → кадрирование «Оригинал» (3:4),
   не «1:1» → подпись и хэштеги дословно (подпись и хэштеги — одним полем, хэштеги в конце через пустую строку) →
   alt-текст, если есть поле → «Поделиться».
4. Reels: «Создать» → «Reels» → `reel.mp4` → обложка — `cover.png` (если есть «Добавить из галереи»; иначе первый
   кадр) → подпись и хэштеги дословно → «Поделиться». Музыку не добавлять (добавит владелец в приложении, если захочет).
5. Не подключать продвижение, соавторов, отметки людей, геолокацию, покупки.
6. Записать ссылку на пост в строку `опубликовано:` этого файла.
7. Сторис для highlights (раздел 2): опубликовать S-01…S-05 в день IG-01, после него. Если сторис из браузера
   опубликовать нельзя — отметить «ждёт владельца: сторис из приложения».

Если запуск позже указанного времени — публиковать сразу, по порядку IG-01 → IG-09, но не больше трёх постов в день:
остальные — на следующий день в то же время.

## 6. Как пересобрать картинки и видео

Все PNG и MP4 собраны скриптом `team/social/assets/render.py` из таблиц этого файла. Если меняется текст слайда или
кадра (например, после вычитки kk), исправьте таблицу здесь и запустите:

```
pip install pillow imageio-ffmpeg
python team/social/assets/render.py
```

Скрипт сам скачает шрифт Inter (OFL) с GitHub google/fonts, если его нет в `team/social/assets/fonts/`.
