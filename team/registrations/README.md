# Регистрации компании — реестр документов

Ведёт сессия «Документация» (решение владельца 30.09.2026). Здесь — **все** программы и платформы, где регистрируется
ТОО «Konsilier AI», и полный комплект документов по каждой. Единые данные компании — [company-card.md](company-card.md).

Хранилище сканов и подписанных документов — закрытая папка Google Drive владельца «Konsilier»
(подпапки «Главные документы», «Заявки в программы»). Корпоративные документы ТОО (устав, решения, приказы, банк) — [corporate.md](corporate.md).

Правило: подаёт владелец (или по его поручению), и **только после записи «подать в …» в `decisions.md`**.

Обновлено: 30.09.2026.
