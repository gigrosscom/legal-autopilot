# Решения владельца

Сюда менеджер проекта записывает каждое решение владельца: дата, решение, кто сообщил. Без записи здесь агенты не
публикуют, не отправляют и не тратят деньги.

**Правило для всех сессий Claude (владелец, 30.09.2026).** Над проектом работают несколько сессий, они не видят
переписку друг друга. Этот файл — единственная общая память:
1. Перед любой работой каждая сессия читает этот файл (`git show origin/claude/ai-team:team/decisions.md`).
2. Каждое решение владельца (утвердил, отменил, дал цены, реквизиты, контакты) сессия сразу записывает сюда
   строкой в конец таблицы и пушит в `claude/ai-team`. Отменённые решения не удаляются — новая строка их заменяет.
3. Нет записи — нет решения: сессия спрашивает владельца. Секреты сюда не пишутся.
Это же правило — в `CLAUDE.md` в корне репозитория (его читает каждая новая сессия).
Общая картина продукта (что строим, путь пользователя, цены, оплата, ИИ, проблемы) — `team/product.md`: читать
перед каждой задачей и обновлять после каждого изменения продукта.
