# Чек-лист модели-судьи: долг / подряд / труд (пилот 03.10)

Каждый пункт — PASS / FAIL / N/A с одной строкой причины. FAIL в 1–4 — ответ не проходит. Нормы —
`.claude/skills/zann-debt-labor-kz`.

1. **Одно решение.** Ответ относит дело к одному виду отношений (заём / подряд / труд / потребитель) и ведёт по одному
   маршруту. FAIL: в одном ответе требование «на номер в мессенджере» + инспекция труда + иск подрядчика.
2. **Квалификация по признакам.** Труд — только при признаках ТК ст. 27 (должность/профессия, лично с подчинением
   распорядку, зарплата за труд); подряд — результат работ, объём, смета, акт (ГК ОЧ ст. 616); заём — передача денег с
   возвратом (ст. 715). Если по словам не решить — один уточняющий вопрос, не догадка.
3. **Верный адресат.** Инспекция труда и согласительная комиссия — только труд. Экономический суд — только если обе
   стороны ИП/юрлица (ГПК ст. 27 ч. 1); физлицо против ТОО — районный суд. Заём по расписке — иск, не судебный приказ.
4. **Юридически верно.** Нет договора — доказывать письменными и иными доказательствами, не свидетелями (ГК ст. 153
   п. 1); цена не согласована — по обычным ценам (ст. 621 п. 1); оплата после сдачи результата (ст. 623 п. 1); срок
   возврата займа без даты — 30 дней с требования (ст. 722 п. 1); давность — 3 года (ГК ст. 178), по труду — 1 год (ТК
   ст. 160). Неустойка за просрочку — ГК ст. 353. FAIL: «без договора ничего не докажете», «3 года» по зарплате.
5. **Документы.** Просит то, что доказывает отношения: подряд — переписка, переводы, акты, сметы, фото работ, пропуска;
   труд — договор/приказ, расчётные листы, выписка ЕНПФ; заём — расписка, переводы. FAIL: «гарантийный талон», «чек
   магазина» подрядчику.
6. **Документ.** Заголовок по спору («Исковое заявление о взыскании стоимости выполненных работ», «… задолженности по
   заработной плате», «… долга по договору займа»); требования с суммой; нормы; цена иска = сумма требования.
7. **Тон.** Спокойно, без оценок контрагента, без обещаний результата; одна понятная следующая мера.

Итог: `pass` — 1–6 PASS; `review` — FAIL только в 6–7; `fail` — любой FAIL в 1–5.
