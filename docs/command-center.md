# Konsiliér Команда — командный центр владельца (/ops)

Одно приложение на телефоне и компьютере: цели месяца с живыми цифрами, команда (6 ИИ-ролей и все сессии Claude),
задачи, решения, отчёты и оперативный центр (оплаты, клиенты, юристы, метрики). Адрес: **https://konsilier.com/ops**.

Это отдельное приложение рядом с клиентским: своё имя («Команда»), своя иконка (тёмная, с синей точкой), свой
манифест `apps/web/public/ops.webmanifest` (scope `/ops`). Клиентское приложение Konsiliér AI не меняется.

## Вход

Ключ администратора — тот же, что для `/admin` (настройка сервера `ADMIN_TOKEN`). Ключ вводится один раз и хранится
только на этом устройстве (в браузере / в установленном приложении). «Выйти» — в меню «Ещё» (телефон) или внизу
боковой панели (компьютер).

Раздел «Операции → Клиенты и юристы» по-прежнему открывается входом по e-mail оператора (как раньше в /ops):
адреса операторов — `OPS_CLIENTS_EMAILS`, `OPS_LAWYERS_EMAILS`. Оплаты владелец подтверждает прямо в «Сводке» по
ключу администратора.

## Установка

Сначала откройте https://konsilier.com/ops и войдите ключом.

- **iPhone / iPad** — только в Safari: «Поделиться» (в Safari 26 — «•••», затем «Поделиться») → «На экран „Домой“»
  → «Добавить». Название на экране — «Команда».
- **Android** — Chrome: кнопка «Установить» вверху экрана (или меню ⋮ → «Установить приложение»).
- **Windows / Mac, Chrome или Edge** — кнопка «Установить» внизу боковой панели (или значок установки в адресной
  строке). Приложение появится в меню «Пуск» / в Launchpad и откроется в своём окне.
- **Mac, Safari** — «Файл» → «Добавить в Dock».

Установленное приложение всегда открывается на /ops. Если на устройстве уже стоит клиентское приложение Konsiliér AI,
это не мешает: это два разных приложения.

## Разделы

На телефоне — вкладки внизу: Сводка, Команда, Задачи, Решения, «Ещё» (Цели и курс, Отчёты, Операции).
На компьютере — все разделы в боковой панели слева.

| Раздел | Что показывает | Откуда данные |
|---|---|---|
| Сводка | Прогресс к цели месяца; пользователи, дела, документы, оплаты, выручка, расходы Claude за день и месяц против лимита; оплаты, ждущие подтверждения (кнопки «Оплата получена» / «Не найдена»); что ждёт вашего решения; последний отчёт | `/v1/admin/metrics`, `/v1/admin/payments`, файлы команды |
| Цели и курс | KPI месяца (100 000 пользователей, 1 000 платных) с живыми цифрами, день месяца и сколько нужно в день; план по каналам; рефералы; вехи первой недели; задачи продукту | `team/README.md`, `team/plan-month-1.md`, метрики. Начало месяца — дата решения о KPI в `decisions.md` |
| Команда | Карточка на каждую ИИ-роль и каждую сессию Claude: чем занята, что сделано, задачи, что ждёт от владельца, показатели | `README.md`, `sessions.md`, `backlog.md`, последний отчёт, `leads/*.csv`, метрики |
| Задачи | Бэклог доской: ждёт владельца / в работе / новые / готово; фильтр по роли, поиск | `team/backlog.md` |
| Решения | «Ждёт вашего решения» и все решения владельца, новые сверху, с поиском | `sessions.md` (колонка «Ждёт от владельца»), `backlog.md` (статус «ждёт…»), блокеры и вопросы последнего отчёта, `decisions.md` |
| Отчёты | Утренние и вечерние отчёты и все остальные файлы папки `team/` (.md и .csv) | `team/reports/`, `team/**` |
| Операции | Оплаты; обращения клиентов, заявки юристу, заявки юристов (вход по e-mail оператора); метрики; ссылка на /admin | как раньше в /ops |

Все цифры — только из метрик сервера и файлов команды. Если данных нет (например, «опубликовано постов»),
приложение так и пишет: «нет данных». Приложение только показывает — файлы команды меняют сессии Claude в ветке
`claude/ai-team`. Новые файлы в `team/` появляются в «Отчётах» сами, без изменений кода.

## Настройки сервера

Файлы команды хранятся не на сервере, а в ветке `claude/ai-team` на GitHub. Сервер читает их сам и кэширует на 5 минут
(кнопка «Обновить» показывает свежие данные не чаще, чем раз в 5 минут).

| Настройка | Нужна ли | Что это |
|---|---|---|
| `ADMIN_TOKEN` | да (уже есть) | ключ входа в приложение |
| `TEAM_GITHUB_TOKEN` | только если репозиторий **закрытый** | токен GitHub только для чтения: Settings → Developer settings → Fine-grained tokens → доступ к одному репозиторию `gigrosscom/legal-autopilot`, права *Contents: Read-only*. Пока репозиторий открытый — не нужен |
| `TEAM_GITHUB_REPO` | нет | по умолчанию `gigrosscom/legal-autopilot` |
| `TEAM_GITHUB_REF` | нет | по умолчанию `claude/ai-team` |
| `TEAM_DIR` | нет | читать файлы с диска сервера вместо GitHub: путь к папке, в которой лежит `team/` (например, клон ветки `claude/ai-team`) |
| `TEAM_CACHE_SECONDS` | нет | время кэша, по умолчанию 300 |

Если сервер не может прочитать файлы (нет сети, закрытый репозиторий без токена, неверный `TEAM_DIR`), разделы
Команда / Задачи / Решения / Отчёты показывают «Файлы команды сейчас недоступны»; цифры и оплаты продолжают работать.

## API (для разработчиков)

Все запросы — с заголовком `X-Admin-Token`.

- `GET /v1/admin/team/files` — список `team/**.md` и `team/**.csv`.
- `GET /v1/admin/team/file?path=team/...` — текст файла (только `team/`, только `.md` / `.csv`).
- `GET /v1/admin/team/bundle` — всё для открытия приложения одним запросом.
- `GET /v1/admin/team/sessions`, `/decisions`, `/reports`, `/reports/<имя>.md`.
- `GET /v1/admin/payments`, `POST /v1/admin/payments/{id}` `{"decision": "paid" | "not_found"}`.
- Ошибка чтения файлов — `503 {"detail": {"code": "team_unavailable"}}`.

Код: `apps/api/konsilier/api/command.py`, `apps/web/app/ops/`, `apps/web/components/command/`.

## Уведомления

Push-уведомления о новых отчётах и оплатах в это приложение пока не сделаны: push на сайте привязан к аккаунту
клиента, а приложение владельца входит по ключу администратора. Письма о новых оплатах по-прежнему приходят на
адреса `OPS_CLIENTS_EMAILS` / `PAYMENT_NOTIFY_EMAILS`, отчёты — push и почтой от команды.
