# Библиотека официальных страниц (вариант «В»)

Консультационный чат отвечает на вопросы о госуслугах, пособиях, грантах, поддержке бизнеса, госзакупках и
процедурах eGov по **официальным страницам**, которые мы сами скачиваем ночью и храним у себя. Во время разговора
ничего не скачивается: поиск идёт по нашей базе и занимает миллисекунды. Живой веб-поиск остаётся только запасным
путём (у Claude — поиск по adilet.zan.kz), а тексты статей законов чат по-прежнему открывает живьём инструментами
юридического агента.

## Что скачивается

Список — данные страны: `packs/<cc>/sources/official.yaml`. Для Казахстана (проверено 29.09.2026):

| Домен | Что берём |
|---|---|
| www.gov.kz | «жизненные ситуации» (`/situations/<n>/intro` — вся ситуация на одной странице: рождение ребёнка, АСП, многодетные, инвалидность, пенсия, алименты, развод, жильё, штрафы, работа…), стандарты госуслуг (`/services/<n>`, найденные в тексте ситуаций), страницы ведомств |
| gfss.kz | социальные выплаты ГФСС (беременность и роды, уход за ребёнком, потеря работы, кормильца, трудоспособности), отчисления, топ вопросов |
| enbek.kz | меры содействия занятости, центры занятости |
| damu.kz | программы фонда «Даму»: субсидии, гарантии, кредиты, лизинг, FAQ |
| old.goszakup.gov.kz | справочные страницы портала госзакупок |

Не берём: egov.kz, zakup.gov.kz, новый adilet.zan.kz — их страницы целиком рисуются скриптом, в HTML нет текста
(законы и так открываются живьём через old.adilet.zan.kz); www.gfss.kz не открывается.

Страницы группируются по темам (seeds): социальные выплаты, поддержка бизнеса, образование, госзакупки, защита
потребителей, труд, жильё, штрафы, семья и алименты, как сделать в eGov. От стартовых страниц краулер идёт по ссылкам
на 1–2 шага, только по разрешённым путям (`include` / `exclude`), не больше 400 страниц на домен.

## Как часто и как вежливо

- Каждую ночь в 03:00 по времени страны (задача планировщика, `OFFICIAL_CRAWL_ENABLED=true`), не дольше 20 минут.
  Не успел — следующая ночь продолжит с того же места (новые и давно не обновлявшиеся страницы — первыми).
- User-Agent `KonsilierBot/1.0 (+https://konsilier.com)`, robots.txt соблюдается (включая `*`, `$` и Crawl-delay),
  не чаще 1 запроса в секунду на домен, только HTML (PDF, архивы, картинки пропускаются), только домены из списка.
- Условный GET (ETag / If-Modified-Since) и хэш извлечённого текста: неизменившаяся страница стоит одного короткого
  запроса и не пишет в базу.

## Сколько стоит

Практически ноль: несколько сотен HTTP-запросов за ночь и несколько мегабайт текста в PostgreSQL. Поиск — полнотекстовый
индекс PostgreSQL (конфигурация `russian` для русского, `simple` для казахского), без внешних сервисов и без LLM.
Замер на реальных страницах: 3–8 мс на запрос в PostgreSQL.

## Как это видит чат

1. Перед вызовом модели по последнему сообщению человека ищутся 3 лучших фрагмента и добавляются в контекст —
   это работает у любого провайдера, даже у того, что не вызывает инструменты.
2. У модели есть инструмент `official_sources` для уточняющего поиска.
3. Правило в промпте: суммы, сроки, пороги дохода и списки документов — только из найденного фрагмента, со ссылкой:
   «По данным <домен>: …». Если в библиотеке ответа нет — так и сказать и назвать портал, где проверить (список
   порталов с описанием тоже из `official.yaml`). Страницы, на которые ответ сослался, сохраняются в `meta.sources`
   сообщения.

## Как добавить источник

1. Проверить, что страницы отдаются сервером: `curl -A "KonsilierBot/1.0 (+https://konsilier.com)" <url>` — в ответе
   должен быть сам текст, а не пустая оболочка для скрипта. Посмотреть robots.txt.
2. Добавить домен в `packs/<cc>/sources/official.yaml`: `domain` (точное имя хоста), `name` и `about` (как чат
   назовёт портал), `include` / `exclude` (регулярные выражения пути), при необходимости `keep_query` /
   `default_query` (например, `lang=ru`), `link_patterns` (ссылки, спрятанные в данных страницы), `hubs` (страницы
   только ради ссылок), `drop` (строки шапки сайта), `max_pages`.
3. Добавить стартовые страницы в `seeds` под нужной темой.
4. Проверить локально и закоммитить только YAML (скачанное не коммитится):

   ```
   DATABASE_URL=sqlite:///./data/official.db alembic upgrade head
   DATABASE_URL=sqlite:///./data/official.db python -m konsilier.cli official-crawl KZ --limit 60
   DATABASE_URL=sqlite:///./data/official.db python -m konsilier.cli official-search "пособие при рождении ребёнка"
   ```

Новая страна — свой `packs/<cc>/sources/official.yaml`; код не меняется.

## Где код

`apps/api/konsilier/official/` — `config.py` (файл источников), `crawler.py` (скачивание, robots.txt, извлечение
текста), `search.py` (поиск), `job.py` (ночная задача); таблицы `official_pages` и `official_chunks` — миграция 0021.
