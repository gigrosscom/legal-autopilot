# Официальные источники права по странам

Данные лежат в `packs/<cc>/pack.yaml` → `legal_sources` (модель `LegalSource` в
`apps/api/konsilier/core/packs.py`), отдаются в `GET /v1/coverage` и показываются на `/coverage`.

**Как проверяли (2026-09-27).** Прямые запросы к сайтам из среды разработки блокируются прокси,
поэтому URL и оператор подтверждены по поисковой выдаче: страницы на самом официальном домене,
сайты министерств и госпорталов, публикации госСМИ и международных организаций.
`verified_on` стоит только у таких записей; без него запись требует ручной проверки.
Официальных API не нашли ни у одной базы: во всех записях `api: unknown`. Это значит «не выяснено»,
а не «API нет». Условия использования процитированы только там, где их удалось прочитать.

Столбец «Доступ»: web — просмотр на сайте; платно — есть платный доступ.

## Как мы их используем

- **Только ссылки и цитаты.** Konsilier.AI ссылается на официальные тексты и цитирует нормы с указанием
  источника (название базы и URL), как требуют условия, например у «Әділет». Юридическую силу имеет текст в
  официальном источнике, а не наша цитата.
- **Законы с «Әділет» для Zann собираем** (решение владельца-юриста 30.09.2026): тексты законов и кодексов РК
  скачиваются для обучения модели Zann — вежливо (пауза между запросами, свой User-Agent), с источником и датой
  (`tools/zann/`). Другие базы без проверки юристом не копируем. Юридическую силу имеет текст в официальном
  источнике; клиентам ссылаемся на него.
- **Судебные решения содержат персональные данные.** Любая их загрузка или обработка требует юридической
  проверки условий, правового основания обработки ПДн и предварительного обезличивания.
- **API.** Официальных API мы не нашли. Если оператор опубликует API или открытый набор данных, запись
  обновляется (`access: api|bulk`, `api: <URL документации>`) только после проверки лицензии.
- **Обновление.** Для нового источника: URL на официальном домене, оператор, `verified_on` только после
  проверки. Тест `apps/api/tests/test_legal_sources.py` требует у каждого пакета хотя бы один источник
  законодательства с https.
